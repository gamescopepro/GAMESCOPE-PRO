GAMESCOPE PRO — Data Sources and Catalog Updates

How the online game catalog gets its information and what its update status means.

Primary game-information source

The current GAMESCOPE PRO online catalog uses the RAWG video game database and API as its primary external source for PlayStation, PC and Xbox game records and related metadata.

Platform coverage

The public catalog accepts a game only when the source identifies at least one PlayStation, PC or Xbox version. A cross-platform game may still be included when it also has an iOS or Android version; games with only mobile, Nintendo or web platforms are excluded.

What information may be available?

Depending on the source record, a game may include its title, cover art, description, platforms, genres, developer, publisher, rating and release date. Not every field is available for every game.

Additional store sources

RAWG currently supplies the cross-platform records used by the site. A dedicated Steam connection using Steam's official Store API is a planned addition and is not yet active. Xbox platform records currently come through RAWG; GAMESCOPE PRO does not claim a direct connection to a public, unrestricted Xbox master-catalog API. Additional providers will be added only after their access and data-use terms are checked.

Automatic refresh

When the homepage is open, its online catalog is designed to refresh periodically in the browser. A separate scheduled server-side synchronization also checks a limited selection of catalog records. A refresh can discover changes only when those changes are present in the upstream source and included in the records checked by that run.

Coverage and accuracy

GAMESCOPE PRO does not claim to list every video game ever made. Third-party databases can contain missing, delayed, estimated or outdated information. Release dates, platforms, availability and publisher details can change. Always verify important details with the game's publisher or official store.

Attribution and independence

RAWG is an external data provider; see its API documentation for information about data access and attribution. GAMESCOPE PRO is an independent project and is not affiliated with RAWG or any console manufacturer or game publisher.
